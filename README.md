# ARTI 308 – Lab 2

## Part 1: Dataset Selection
The dataset used in this lab focuses on work-from-home habits and burnout risk.
It includes information such as working hours, screen time, meetings, sleep hours,
and burnout indicators

## Part 2: Machine Learning Problem Definition
This is a classification problem.
The target variable is burnout_risk.
The model aims to predict burnout risk based on work-from-home behavior.

This problem aims to use work-from-home data to analyze employee behavior,
and then classify them according to their burnout risk level based on their daily work patterns.
